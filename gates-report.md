## Could not verify / open issues
- merge.py aliases story `craft_terrain_manipulator` to crafting `install_terrain_manipulator`, which says the blueprint is bought (merchant, 50 nanites). Awakenings gives it free. I could not edit those files, so build_basic_shelter and build_base_computer no longer depend on it (otherwise a false nanite gate would hit the whole opening). Suggest removing that alias or relaxing install_terrain_manipulator.
- Emeril material source: the wiki Indium Drive page gives the recipe (250 Emeril) but not where Emeril is mined; warp_blue therefore has no warp_green gate (kept from the earlier fix). Real game may effectively require reaching green systems.
- Dreams of the Deep alternate start (Pioneer = 40 warps) has no matching objective, so the gate stays complete_16_16 (stricter than the game).
- Journey milestone chain: totals are cross-category counts; a few categories may need first_warp etc., not encoded.
- Atlas Path first station can start without the Anomaly (accidental warp into an Atlas Station), but the Anomaly route is encoded implicitly via complete_awakenings.
- The Settlers/answer_settlement_emergency_broadcast gate on first_warp is not stated on any wiki page (left as is).
- A Trace of Metal on Nintendo Switch triggers differently (not applicable on other consoles); platform not specified so only the standard path is encoded.
- Whether the Hermetic Seal repair step must precede the Analysis Visor mission follows the wiki order; not verified in-game.
